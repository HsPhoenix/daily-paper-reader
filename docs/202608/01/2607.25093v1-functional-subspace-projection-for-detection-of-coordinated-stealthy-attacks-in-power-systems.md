## 摘要
现代电网日益容易受到协同网络攻击，特别是能够规避传统基于残差检测器的虚假数据注入攻击（FDIA）。虽然大多数现有检测方法依赖于瞬时测量，但协同动态攻击可以在每个时间步保持隐蔽，同时引入结构化的时间偏差。本文开发了一个联合框架，用于建模和检测多区域电力系统中的此类攻击。首先构建了一个时间聚合攻击模型，以捕捉时间演化和区域间协同。在检测方面，提出了一种核嵌入功能子空间检测（KEFSD）方法，该方法在再生核希尔伯特空间（RKHS）中对残差轨迹进行建模，并采用RKHS约束的功能主成分分析（PCA）来识别异常时间模式。在修改后的IEEE 14节点系统上的仿真结果表明，与传统的基于残差的2范数检测器相比，所提出的方法实现了更好的检测性能。

## Abstract
Modern power grids are increasingly vulnerable to coordinated cyber-attacks, particularly false data injection attacks (FDIAs) that can evade conventional residual-based detectors. While most existing detection methods rely on instantaneous measurements, coordinated dynamic attacks can remain stealthy at each time step while introducing structured temporal deviations. This paper develops a joint framework for modeling and detecting such attacks in multi-area power systems. A time-aggregated attack model is first formulated to capture temporal evolution and inter-area coordination. For detection, a kernel-embedded functional subspace detection (KEFSD) method is proposed, which models residual trajectories in a reproducing kernel Hilbert space (RKHS) and employs RKHS-constrained functional principal component analysis (PCA) to identify anomalous temporal patterns. Simulation results on a modified IEEE 14-bus system demonstrates the proposed method achieves improved detection performance compared to the conventional residual based 2-norm detector.

### 2. 论文提出的方法论

#### 核心思想
- 将残差信号视为**时间轨迹函数**，而非孤立采样点。
- 把这些轨迹嵌入**再生核希尔伯特空间（RKHS）**中，利用函数型数据分析手段提取正常模式。
- 在线检测时，将新到来的残差轨迹向正常子空间做投影，投影残差能量越大则越可能受到攻击。

#### 关键技术细节
- **动态攻击建模**：
  - 系统以微分代数方程描述发电机摆动方程与网络潮流约束。
  - 测量模型线性化后，攻击残差近似为 \(r(t) \approx R a(t)\)，其中 \(R\) 是残差灵敏度矩阵。
  - 攻击信号参数化为 \(a_k(t) = c(t) \mu_k\)，\(c(t)\) 为已知时间策略（如正弦、占空比），\(\mu_k\) 为各区域攻击空间分布向量。
  - 攻击设计问题为：在残差范数低于检测阈值、攻击向量的1-范数稀疏约束下，最大化攻击对状态估计的影响（同时考虑跨区域协调惩罚项）。
  - 由于问题非凸，使用**投影梯度上升算法（PGA）**求得局部最优解。

- **KEFSD 检测方法**：
  1. **RKHS建模**：每个残差通道 \(r_i(t)\) 通过正则化最小二乘拟合成 RKHS 函数 \(g^{\text{nom}}_i(t)=\sum_j \alpha_{ij}\kappa(t,t_j)\)，系数由 \((K+\lambda I)^{-1} r_i\) 给出。
  2. **RKHS约束的功能PCA**：构造残差样本协方差 \(\Sigma_m\)，在最大化方差的同时加入 RKHS 范数惩罚项 \(\gamma K^{-1}\)，求解约束优化问题得到主方向 \(Z\)。最终重建为函数型主成分 \(f_\ell(t)\)。
  3. **在线投影检测**：用滑动窗口估计当前残差轨迹 \(\hat{g}_i\)，计算其在正常子空间 \(\mathcal{F}^* = \operatorname{span}\{f_1,\dots,f_r\}\) 上的正交投影残差能量 \(J_i(t_s)\)，并在区域层面聚合得到检测统计量 \(J^{(k)}(t_s)\)，当超过阈值 \(\tau^{(k)}\) 时触发警报。

- **公式与算法**：
  - 攻击设计（公式10）：\(\max_{\{\mu_k\}} \alpha \sum_k \|Q_k\mu_k\|_2^2 - \sum_{k,l} w_{kl}\|Q_k\mu_k - Q_l\mu_l\|_2^2\)，约束为 \(\|c(t)R_k\mu_k\|_2 \le \epsilon_k\)、\(\|\mu_k\|_1 \le \rho_k\)。
  - 检测投影（公式21–23）：\(\Pi_{\mathcal{F}^*} \hat{g}_i = \sum_\ell \langle \hat{g}_i, f_\ell\rangle_{\mathcal{H}_\kappa} f_\ell\)，\(J^{(k)} = \frac{1}{m_k}\sum_i \|(I-\Pi_{\mathcal{F}^*})\hat{g}_i\|^2_{\mathcal{H}_\kappa}\)。
