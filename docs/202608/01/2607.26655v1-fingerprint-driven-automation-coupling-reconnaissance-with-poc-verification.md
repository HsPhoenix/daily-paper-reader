## 摘要
在网络安全对抗领域，侦察是第一步也是最关键的一步。准确、高效、全面的侦察能够帮助网络安全人员更全面地了解目标现状，发现潜在弱点，并制定针对性的攻击策略。然而，市场上现有工具存在一些问题，如收集信息准确率低、隐蔽性不足、耗时，以及工具集成度或高或低，导致难以入手使用。随着技术的不断发展，系统需要持续升级技术和策略，并拓展新功能。工具功能的可扩展性也是需要考虑的因素之一。这些网络安全实践中的问题严重影响用户体验和工作效率。鉴于此，设计了一款更友好、更自动化的侦察与漏洞验证工具。本文提出开发一款高度自动化的侦察与漏洞验证工具。本文介绍了工具功能并进行了基本设计。最后，我们具体实现并测试了所有功能，以验证工具功能的可行性，并突出该工具在自动化、检索及网络安全操作使用方面的优势。通过在线安全模拟靶场的测试，结果表明该工具能够完成特定目标的自动侦察和深度数据处理，并进行自动漏洞检测与验证。

## Abstract
In the field of network security confrontation, reconnaissance is the first and most critical step. Accurate, efficient, and comprehensive reconnaissance can help network security workers more fully understand the target's current state, identify potential weaknesses, and formulate a targeted attack strategy. However, there are some problems in the existing tools on the market, such as low accuracy of the collected information, lack of concealment, time-consuming, low or high integration of tools, which makes them difficult to start using. With the continuous development of technology, systems need to continuously upgrade their technologies and strategies, and expand new functions. The scalability of tool functions is also one of the factors that need to be taken into consideration. These problems in the practice of network security have a serious impact on user experience and work efficiency. In view of this, a more user-friendly, more automated reconnaissance and vulnerability verification tool is designed.This paper proposes to develop a highly automated reconnaissance and vulnerability verification tool. This paper presents the tool functions and conducts the basic design. Finally, we implement and test all the functions specifically to verify the feasibility of the tool functions and highlight the advantages of this tool in terms of automation, retrieval, and use in network security operations.Through the test of the online security simulation range, the results show that this tool can complete the automatic reconnaissance and in-depth data processing of specific targets, and conduct automatic vulnerability detection and verification.

  - **框架定制检测系统**（如 WPscan 针对 WordPress）：仅能覆盖特定技术栈，难以应对复杂异构 Web 环境。

## 二、论文提出的方法论

### 1. 核心设计思想

- **指纹驱动（Fingerprint-Driven）**：在侦察阶段提取目标多维指纹（HTTP 响应头、页面内容、静态资源特征、技术栈类型、服务器版本、框架信息等），将指纹作为“中间纽带”，动态匹配并调用对应的 PoC 验证脚本，从而：
  - 让渗透测试更有针对性，避免盲目遍历所有已知漏洞；
  - 减少网络流量开销，降低误报率；
  - 实现侦察结果到验证动作的自动映射，替代人工桥接。

### 2. 系统架构

系统由三大模块组成，底层代码独立解耦，逻辑上通过标准化内部数据接口串联：

| 模块 | 功能 |
|---|---|
| 多维基础信息侦察模块 | 非侵入式资产测绘与基础信息提取，构建目标画像 |
| 指纹驱动扫描与识别模块 | 基于前期画像进行指纹匹配与定向检测，避免盲目扫描 |
| 异构数据聚合处理模块 | 对多源检测数据进行清洗、结构化处理，为 PoC 触发与漏洞验证提供数据支撑 |

### 3. 关键功能模块设计

- **用户界面**：提供终端 CLI 和 Web 图形界面（Flask + Bootstrap）。CLI 使用 pyfiglet 生成 ASCII 艺术横幅，并在扫描前回显全局配置参数，保证执行透明性。

- **WebInfo 信息收集**：
  - 通过 DNS 解析获取真实 IP（过滤内网/回环地址）；
  - 使用 GeoLite2-City.mmdb 进行 IP 地理定位；
  - 提取网页标题、服务器类型、操作系统信息；
  - 集成 CDN 与 WAF 检测：CDN 通过“IP 段匹配 + ASN 溯源”双重识别；WAF 通过注入恶意 payload 触发特征并匹配本地 WAF 指纹库。

- **端口/目录扫描**：
  - 端口扫描：基于完整 TCP 连接，多线程加速，并兼顾“端口欺骗”场景（开放端口超过 30 个即提示）；
  - 目录扫描：采用动态字典生成（Cartesian 笛卡尔积生成文件名组合）、404 误报检测（构造无效 URL 提取自定义 404 页面特征）、响应内容语义验证（过滤“软404”）、重定向合法性校验，以及在不同操作系统上选用多线程或异步 I/O（uvloop）的并发策略。

- **服务指纹识别**：
  - 采用两层指纹机制：第一层用 WebPage 类解析 HTML、响应头、script src、meta 信息，基于 `apps.txt` 规则进行正则匹配；第二层用 Wappalyzer 类加载 `apps.json` 复杂规则库，识别 CMS、论坛、电商系统等应用类型。

- **PoC 验证**：
  - 将侦察阶段获取的开放端口、应用指纹等信息传入 PoC 脚本的 `check` 函数，判断是否满足执行条件，并评估执行结果；支持多线程并发运行多个 PoC；
  - PoC 脚本需按具体漏洞机制定义 `check` 函数，但参数接口标准化，便于扩展。

- **数据库设计**：
  - 采用 SQLite3 作为存储引擎，设计四个核心实体：WebInfo（网站基本信息）、Ports（端口信息）、Urls（目录/文件信息）、Vulns（漏洞信息），其中 WebInfo 与其他实体均为 1:N 关系。

- **报告生成**：
  - 三通道输出：终端实时输出（时间—模块—结果）、HTML 可视化报告（Vue.js + Bootstrap 模板）、SQLite 数据库文件（可用 Navicat 等工具查看）。
