## 摘要
分布式点函数（DPF）是一种密码学原语，它能够在两方或多方之间实现对秘密权重为1的向量（等价地，点函数）的压缩加性共享。DPF构造所具有的简洁轻量结构使其得以应用于广泛场景，包括私有信息检索、匿名通信、带预计算的安全计算，以及用于将小型相关种子扩展为大规模伪随机密码相关性实例的伪随机相关性生成器。本文综述了DPF的定义、构造及应用，并讨论了DPF向函数秘密共享（FSS）的扩展，该扩展将点函数推广至支持更丰富的函数类。高效的FSS方案能够对DPF的大多数应用实现类似的推广。

## Abstract
A distributed point function (DPF) is a cryptographic primitive that enables compressed additive sharing of a secret weight-1 vector (equivalently, a point function) across two or more parties. The appealing lightweight structure of DPF constructions has enabled a wide range of applications. These include private information retrieval, anonymous messaging, secure computation with preprocessing, and pseudorandom correlation generators for expanding small correlated seeds into large pseudorandom instances of cryptographic correlations.   In this article, we survey definitions, constructions, and applications of DPFs. We also discuss the extension of DPF to function secret sharing (FSS), which generalizes point functions to support richer function classes. Efficient FSS schemes yield a similar generalization for most of the applications of DPFs.

## 1. 核心问题与整体含义

- **研究动机**：秘密共享是密码学的核心工具，但完美安全的加性秘密共享无法压缩共享大小。在计算安全假设下，借助伪随机生成器（PRG）可实现有限压缩。然而，对于一般向量，总共享大小仍至少为向量长度。  
- **核心问题**：当秘密向量具有短描述（例如权重为1的“独热向量”/点函数）时，能否构造压缩的加性秘密共享，使每个密钥远小于向量规模，同时支持对任意位置的随机访问？  
- **整体含义**：分布式点函数（DPF）正是针对“点函数”这一特殊函数类的压缩秘密共享原语。其轻量结构催生了私有信息检索、私有写入、匿名通信、预计算安全计算、伪随机相关性生成器（PCG）等广泛应用，并可通过函数秘密共享（FSS）推广到更丰富的函数类，从而拓展了应用边界。这篇综述系统梳理了DPF/FSS的定义、构造、应用与开放问题，是该领域的权威导览。

## 2. 方法论：核心思想与关键技术细节

### 2.1 形式化定义
- **FSS**：将秘密函数 \(f \in \mathcal{F}\) 拆成两个函数共享 \(f_0, f_1\)，满足对任意输入 \(x\)，\(f_0(x)+f_1(x)=f(x)\)，且每个 \(f_i\) 在计算上隐藏 \(f\)（允许泄漏 \(Leak(f)\)）。
- **DPF**：对点函数 \(f_{\alpha,\beta}(x)=\beta\)（若 \(x=\alpha\)）否则为 0 的FSS。密钥大小要求远小于定义域规模 \(2^n\)。
- **扩展**：包括多方DPF（\((m,t)\)-DPF）、分布式比较函数（DCF）、分布式多点函数（DMPF）、乘法DPF等。

### 2.2 两方DPF构造
- **平方根构造**（Chor-Gilboa）：将输入域看成 \(\sqrt{N}\times \sqrt{N}\) 矩阵，利用按行共享PRG种子和一行校正词，密钥大小为 \(O(\sqrt{N})\)。
- **树形构造**（Boyle-Gilboa-Ishai 2016，最优）：
  - 每个密钥定义一棵GGM风格二叉树，根标签包含随机种子和控制位；
  - 借助加性秘密共享的两个同态性质：线性同态（条件校正）和PRG同态（相同种子扩展为相同串，异或抵消）；
  - 维护不变量：非特殊路径上的节点两树标签相同；特殊路径（通向秘密点）上的节点控制位异或为1，种子独立伪随机；
  - 每层设置校正词（correction word），特殊路径上通过校正词强制离径子节点两树一致，同时保持径上节点伪随机；
  - 最后通过额外校正词安装输出值 \(\beta\)。
- **最终参数**：密钥大小约 \(n(\lambda+2)+\lambda+\log|G|\) 比特（\(\lambda\) 为安全参数，通常128）。

### 2.3 多方DPF与变体
- **\((m,1)\)-DPF**：基于CNF秘密共享，可实现乘法共享，支持本地计算低次多项式；密钥大小 \(O(mn(\lambda+\log m)+m^2\log|G|)\)。
- **\((m,m-1)\)-DPF**（全阈值）：仅知平方根级别方案（如Boyle等2015，Goel等2025），密钥大小为 \(2^{n/2}\cdot \mathrm{poly}(m,\lambda)\)。
- **\((m,t)\)-DPF（\(1<t<m-1\)）**：可通过组合全阈值DPF与乘法分享，密钥大小与 \(2^{n/(2d)}\) 相关（其中 \(m=td+1\)）。
- **DCF**：可通过 \(n\) 个DPF组合实现，但树形DPF略加修改可直接得到DCF，密钥大小与DPF相当。
- **DMPF**：用于共享权重为 \(t\) 的稀疏向量，主要构造有：朴素（t个DPF之和）、大状态（big-state）DPF、基于概率批处理码（PBC）的构造、基于OKVS的构造，各有不同参数优势。

### 2.4 信息论DPF与一般FSS
- 信息论DPF在 \(t<m/2\) 时存在，基于Reed-Muller码可得密钥 \(N^{1/(m-1)}\)；还可借助2-server PIR方案构造4方完美安全DPF和3方统计安全DPF，密钥大小可达 \(N^{o(1)}\)。
- 一般FSS的构造依据假设层级：
  - 仅用OWF/PRG：点函数、比较/区间、多点函数、NC⁰函数、决策树等；
  - 用LPN类假设：低次多项式HSS；
  - 用公钥假设（DDH/DCR/LWE）：分支程序、一般电路等。

## 6. 主要结论与发现

- DPF是高效的压缩点函数共享原语，**两方DPF在PRG假设下密钥大小可达 \(O(n\lambda)\)**，这是目前最优。
- 多方DPF的效率强烈依赖腐败阈值：全阈值设置下目前仍受限于平方根密钥大小，这是一个核心开放问题；而 \((m,1)\) 或低阈值设置可实现高效构造并支持乘法共享。
- DCF、DMPF等变体显著拓展了DPF的功能，且DMPF的构造选择需要根据权重 \(t\) 和评估模式具体权衡。
- FSS是更一般的抽象，其可行性随函数类复杂度和假设强度变化：点函数等简单类只需PRG，分支程序/电路则需要公钥假设。
- DPF/FSS已经成功应用于隐私检索、私有统计、匿名通信、安全计算预计算和伪随机相关性生成器等领域。
- 提出了若干关键开放问题：改进两方DPF密钥大小、突破多方全阈值平方根障碍、FSS for conjunctions、高效的分布式Gen、信息论3方DPF等。
