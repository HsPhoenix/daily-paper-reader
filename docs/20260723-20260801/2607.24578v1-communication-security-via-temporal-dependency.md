## 摘要
通信安全传统上建立在两种外部资源之一上：共享密钥或相对于窃听者的通信优势。然而，许多实际无线场景，包括无基础设施、紧急和高度动态的网络，无法保证这两种资源中的任何一种，因此需要一种新的通信安全原则。本文提出了一种新的通信安全范式，利用时间依赖作为安全资源。与防止窃听者恢复传输比特的传统保密技术不同，所提出的范式允许数据包解码，但通过使原始数据包和虚拟数据包在计算上不可区分来防止正确解释。不是保护单个传输，而是有意耦合连续传输，使未来通信依赖于正确解释先前的传输。作为实现方式，我们开发了一种状态链随机线性网络编码（RLNC）框架，其中解释每个传输块所需的同步状态嵌入在前一块中。因此，同步失败会传播到未来的传输，导致窃听者持续失步。我们在分析上表征了窃听者失步的概率和持续性，以及重新同步的计算复杂度，并基于发射功率和有意干扰优化开发了传输策略。数值结果展示了在最坏情况对抗模型下亚秒级的窃听者失步，该模型没有信道优势、没有秘密假设、完全了解协议，并且窃听者任意强大。

## Abstract
Communication security has traditionally been built upon one of two external resources: shared secret keys or a communication advantage over the eavesdropper. However, many practical wireless scenarios, including infrastructure-less, emergency, and highly dynamic networks, cannot guarantee either resource, motivating the need for a new communication security principle. This paper introduces a new communication security paradigm that exploits temporal dependency as a security resource. Unlike conventional secrecy techniques that prevent an eavesdropper from recovering transmitted bits, the proposed paradigm allows packet decoding but prevents correct interpretation by making original and dummy packets computationally indistinguishable. Rather than protecting individual transmissions, successive transmissions are intentionally coupled so that future communication depends on correctly interpreting previous ones. As one realization, we develop a state-chained random linear network coding (RLNC) framework in which the synchronization state required to interpret each transmission block is embedded in the previous block. Therefore, synchronization failures propagate across future transmissions, resulting in persistent eavesdropper asynchronization. We analytically characterize the probability and persistence of eavesdropper asynchronization, together with the computational complexity of resynchronization, and develop transmission strategies based on transmit power and intentional-interference optimization. Numerical results demonstrate sub-second eavesdropper asynchronization under a worst- case adversarial model with no channel advantage, no secret assumptions, complete protocol knowledge, and an arbitrarily stronger eavesdropper.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：现有通信安全主要依赖两大范式：**密码学安全**（依赖共享密钥）和**物理层安全**（依赖信道优势，如CSI、波束成形、人工噪声、协同干扰等）。然而在无基础设施网络、应急通信、无人机群、卫星通信等高度动态无线场景中，这两种资源都难以保证。
- **核心问题**：能否设计一种**不依赖外部资源**的通信安全机制，仅从通信过程本身提取保护能力？
- **核心洞见**：传统安全方案将每次传输视为独立安全事件——单次传输被破解不会影响后续传输。本文提出**时间依赖（Temporal Dependency）**作为新的安全资源：将连续传输有意耦合，使未来通信的正确解释依赖于此前传输的正确解释，从而将单次同步失败转化为**持续性失步**。
- **范式转变**：从"防止窃听者解码"转向**"允许解码、但防止正确解释"**，将安全目标从分组恢复（packet recovery）转为分组解释（packet interpretation）。
- **对比现有安全范式**：密码学安全在密钥泄露后所有未来通信永久暴露；物理层安全在信道优势消失后安全即失效；而时间依赖安全通过反复诱发窃听者失步来持续重建不确定性，无需密钥或信道优势。

### 2. 方法论：核心思想、关键技术细节

#### （1）核心框架：状态链式随机线性网络编码（State-Chained RLNC）

- **基本结构**：每个传输块包含 `N` 个分组，其中 `N−D` 个为原始数据分组（`x`），`D` 个为虚拟分组（`d`）。长度为 `N` 的二进制状态向量 `s` 指示虚拟分组的位置（权重为 `D`）。
- **同步状态嵌入**：块 `b+1` 的同步状态 `s(b+1)` 在块 `b` 传输开始时随机生成，通过**可逆秘密共享映射** `S(·)` 嵌入到块 `b` 的 `D` 个虚拟分组中。状态恢复函数为 `s(b+1) = C(d(b)) = L⁻¹(⊕dᵢ)`。
- **RLNC编码**：原始分组与虚拟分组按状态向量插入后，构成块分组向量 `p(b)`，随后进行标准RLNC编码传输（编码系数服从对称伯努利分布）。
- **解释条件**：窃听者即便成功解码整个RLNC块，也必须知道状态向量 `s` 才能区分原始分组和虚拟分组，从而正确解释数据——虚拟分组设计为与原始分组在统计和语义上完全不可区分。
- **失步传播机制**：若块 `b` 的状态向量不在窃听者解码矩阵的行空间中，则无法恢复 `s(b+1)`；而 `s(b+2)` 又嵌入在块 `b+1` 中，因此失步将**无限传播**。合法接收者Bob始终保持同步，可正确解码每一块。

#### （2）关键分析定理

- **定理1（Bob满秩时间分布）**：给出了Bob解码矩阵恰好满秩时刻 `T` 的概率密度函数 `f_B(t=T)`，由组合计数和概率论推导。
- **定理2（失步概率）**：给出了窃听者失步概率 `P_asy` 的精确闭式表达式，对Bob解码时间、ACK延迟、Eve分组接收过程进行逐层条件化平均。
- **推论1（首次失步时间）**：`τ_asy = τ_q / P_asy × (N + 1.6/P_B + E[T_ack])`，给出了预期失步间隔。

#### （3）优化设计

- **P1（发射功率优化）**：在吞吐率、时延、计算安全约束下最小化 `τ_asy`，优化变量为发射功率 `P`。

### 6. 主要结论与发现

1. **基线表现**：即使Eve信道比Bob强10 dB（此时传统保密容量为零或为负），在 `T_ack = 2 ms` 时，失步时间仍保持在约10–30秒以内。
2. **功率优化效果显著**：P1优化可将失步时间降至约10–20秒（Eve强10 dB），在信道条件相近时可降至**1秒以下**；最优功率通常在约0.01 W（信道条件相近时），因低功率可延缓Bob满秩以缩短Eve的观测窗口。
3. **有意干扰的根本性优势**：P2在 `Ω_E = ∞` 最坏假设下，对 `T_ack = 2 ms` 的所有吞吐率需求都实现了**亚秒级失步**；`T_ack = 5 ms` 时在吞吐率约600分组/秒以下保持亚秒级。这证明时间依赖安全可彻底规避Eve的信道优势。
4. **重同步计算不可行**：对 `N = 120` 且 `D = 20` 时，Eve维持同步所需的计算时间超过**10年**；即使使用100块B200 GPU，D在14→18的微小增加也会使重同步时间从约1天跃升至数年。
5. **核心结论**：通信安全可以在**无需密钥保密、无需信道优势**的条件下实现，为无基础设施和高度动态无线网络提供了全新安全原理。

### 7. 优点

- **范式创新性**：首次系统性地以"时间依赖"作为通信安全的**独立资源**，与密码学和物理层安全形成三足鼎立的新方向。
- **威胁模型的强保守性**：假设Eve拥有完整协议知识、知道密钥、无信道劣势（甚至任意强），是当前文献中最强的对抗假设之一。
- **理论分析的完整性**：从Bob满秩时间分布到失步概率再到重同步复杂度，建立了完整的概率分析框架；复杂组合推导（定理2）在技术上具有高难度。
- **实用导向**：仅依赖通信中已有的ACK反馈，无CSI要求、无密钥管理负担，适合无基础设施场景。
- **计算的不可行性设计**：通过组合爆炸式的重同步计算代价，使窃听者即使计算能力极强也无法维持同步，提供了可量化的安全级别。
- **安全概念的转变**：允许"解码但阻止解释"的思路，为未来通信安全提供了全新的设计空间。

### 8. 不足与局限

- **安全性未完全覆盖**：作者明确承认**首个传输块**的同步状态是公开的，其机密性不保证；若Eve在系统刚启动时恰好保持了同步且从未失步，则存在持续窃听的可能。
- **实现依赖不可区分性假设**：方案安全性建立在"原始分组与虚拟分组在统计和语义上完全不可区分"的基础上。若应用层数据具有可验证的结构（如校验和、协议头语义），则需额外处理以保证不可区分性。
- **ACK延迟的双刃剑效应**：长ACK延迟延长了Eve的观测窗口，显著恶化安全性能（T_ack=10 ms时即使P2优化也难达亚秒级），作者承认需结合分组交织等额外手段。
- **缺乏真实系统验证**：全部结果来自数值仿真，在真实无线信道（信道估计误差、非理想交织、实际编码调制）下的表现未经验证。
- **通用性有限**：分析结果和优化策略特化于RLNC实现，虽称为"范式"，但其他实现方式的可行性未被探讨。
- **无能量/开销分析**：未讨论有意干扰带来的额外能耗、对Bob的SNR损失，以及状态链RLNC的计算和通信开销。
- **未与其他方案直接对比**：缺少与经典加密、物理层安全方法在相同场景下的安全性/吞吐率/延迟权衡的系统性对比。
- **未建模Eve的适应性**：假设Eve仅使用暴力搜索重同步，未考虑Eve可能使用机器学习、侧信道或协议层信息辅助识别虚拟分组的对抗策略。
