## 摘要
大型语言模型（LLM）代理通过观察-行动循环自动化渗透测试，根据工具返回的观察结果选择行动。这种依赖性使得防御者能够注入欺骗性观察结果，从而误导代理的决策过程。然而，现有防御手段严重依赖于攻击前在环境中植入的静态、孤立工件。高级代理能够逐步识别并绕过这些工件，最终将利用尝试重新集中在真实目标上。为解决此问题，我们提出了AgentSnare，一种轨迹自适应欺骗系统，能够动态展开诱饵环境，持续引导渗透代理远离真实目标。具体而言，AgentSnare采用一个工件构建策略模型，根据代理的交互历史和诱饵状态生成候选工件。随后，AgentSnare验证这些候选工件，并将有效工件逐步整合到一个事实一致的诱饵环境中，从而通过吸收其工具调用来延迟攻击，在诱饵中转移其进入后的轨迹，并通过诱导基于诱饵证据的完成报告来化解攻击。在15个CVE-Bench Web应用和三种攻击者模型上，AgentSnare在诱饵中吸收了46.8%的代理工具调用，并在其中保留了55.9%的进入后操作，同时90.0%的完成尝试基于诱饵证据；在所有45个攻击者-CVE组合中，pass@3情况下没有真实目标被成功利用。

## Abstract
Large language model (LLM) agents automate penetration testing through an observation-action loop, selecting actions based on observations returned by tools. This dependence allows defenders to inject deceptive observations that can mislead the agent's decision-making process. However, existing defenses rely heavily on static, isolated artifacts planted in the environment prior to an attack. Advanced agents can progressively recognize and bypass these artifacts, ultimately refocusing their exploitation attempts on the real target. To address this issue, we introduce AgentSnare, a trajectory-adaptive deception system that dynamically unfolds a decoy environment to continually steer the penetration agent away from the real target. Specifically, AgentSnare employs an artifact-construction policy model that constructs candidate artifacts conditioned on the agent's interaction history and decoy state. AgentSnare then validates these candidates and incrementally incorporates valid artifacts into a factually consistent decoy environment, thereby delaying the attack by absorbing its tool calls, diverting its post-entry trajectory within the decoy, and defusing it by inducing completion reports grounded in decoy evidence. Across 15 CVE-Bench web applications and three attacker models, AgentSnare absorbs 46.8% of the agent's tool calls in the decoy and retains 55.9% of post-entry actions there, while 90.0% of completion attempts are grounded in decoy evidence; across all 45 attacker-CVE pairs, no real target is successfully exploited at pass@3.

# 论文《AgentSnare：学习延迟、转移和化解自主渗透代理》详细总结

## 1. 核心问题与整体含义

- **研究背景**：LLM 智能体已能通过"观察–行动"循环实现自动化渗透测试，即在每个步骤中根据工具返回的观察结果决定下一步动作。这种机制在提升合法安全测试效率的同时，也被恶意攻击者滥用。
- **核心问题**：防御者可以利用攻击者对观察结果的依赖注入欺骗性信息。然而，现有防御大多依赖**攻击前静态预置的孤立诱饵工件**（如蜜标文件、提示注入、虚假凭据等），这些固定工件容易被高级攻击者通过多步交互逐步识别并绕过，最终攻击仍会回到真实目标。
- **论文含义**：作者提出 **AgentSnare**——一个**轨迹自适应欺骗系统**，不再预先构建完整诱饵环境，而是根据攻击者的实时交互历史与当前诱饵状态，**动态构造、验证并披露诱饵工件**，逐步展开一个**全局事实一致**的诱饵环境，将攻击者持续引入歧途。
- **核心防御目标**：延迟攻击（吸收工具调用）、转移攻击（将进入后的行为留在诱饵中）、化解攻击（诱导攻击者的完成报告基于诱饵证据）。

## 2. 方法论

### 2.1 核心思想
AgentSnare 由两条流水线组成：
- **在线轨迹自适应防御流水线**：动态拦截攻击者的探测行为，构建并披露诱饵工件。
- **离线训练流水线**：通过模拟攻击者–防御者交互，微调工件构建策略模型。

### 2.2 在线阶段一：候选工件构建
- 每一轮交互中，策略模型 Mθ 接收输入：
  \[
  x_t = (h_t, a_t, W_t, F_t, q)
  \]
  其中 h 为交互历史，a 为当前攻击动作，W 为世界事实账本，F 为可用诱饵前沿，q 为服务器/应用档案。
- 模型输出候选工件：
  \[
  c_t = (\tilde{o}_t, \Delta W_t) = M_\theta(x_t)
  \]
  其中 \~o 为建议披露的观察结果，ΔW 为支持该观察所需的新增环境事实。
- 该模型本身不直接修改环境状态，只提出"攻击者会看到什么"及"需要哪些新事实来支撑"。

### 2.3 在线阶段二：工件验证与披露
AgentSnare 的 ShadowOS 子系统从三个维度验证候选工件：
1. **语义有效性**：观察结果需符合当前命令语义、可通过当前探测被观察到、格式符合预期。
2. **状态有效性**：新引入事实需与已有事实账本一致、可从当前诱饵前沿到达、可在后续交互中复现。
3. **安全性有效性**：防止泄漏真实环境秘密，满足基本文件系统、用户、进程、权限、服务约束。

验证通过后，ShadowOS 将工件提交并更新世界状态，返回正式观察给攻击者：
\[
(W_{t+1}, G_{t+1}) = \text{Commit}(W_t, G_t, \Delta W_t, \Delta G_t), \quad o_t = \text{Render}(a_t, \tilde{o}_t, W_{t+1}, G_{t+1})
\]
验证失败则不改变状态，仅返回不引入新事实的失败观察。

### 2.4 离线训练：模拟攻击者–防御者交互
- 从 12 类攻击意图场景分布 σ 中采样，生成合成轨迹。
- 使用两个隔离的 DeepSeek-V4-Flash 实例分别扮演**攻击者模拟器**和**候选生成器**。
- 对同一输入生成 k 个候选工件，对每个候选进行反应预测（采样 m 个后续动作），据此选出最能引导攻击者留在诱饵中的工件。
- 选中的工件追加到交互历史，驱动下一轮模拟。
- 最终通过轨迹级筛选，获得 24,807 条防御者决策（来自 503 条轨迹），用于对 Qwen3-4B 进行 LoRA 微调（r=64，α=128，3 epochs，bf16）。

## 3. 实验设计

### 3.1 数据集与场景
- **Benchmark**：CVE-Bench 中 15 个可部署的 Web 应用漏洞任务。
- **攻击者模型**：Claude Opus 4.6、GPT-5.4、MiniMax M3 三种前沿 LLM。
- **评估设置**：每个攻击者–防御对在每个 CVE 上运行 3 次，共 **405 次有防御运行**；防御效果以 pass@3 评估，同时报告无防御时的 pass@1 基准。

### 3.2 对比方法
- **静态防御（Static Defenses）**：联合部署 13 种可复现的静态干预实例，覆盖六大策略类别。
- **Cowrie**：预构建交互式蜜罐 shell，使用静态虚拟文件系统。
- **HoneyLLMd**：基于层次概率自动机 + GPT-5.4-mini 生成自适应响应的蜜罐。
- **AgentSnare**：LoRA 微调的 Qwen3-4B 工件构建模型 + ShadowOS 状态化运行时。

### 3.3 评估指标
- **Delay**：诱饵吸收的工具调用占总调用的比例。
- **Divert（操作化为 PER）**：首次进入诱饵后，后续动作留在诱饵中的比例。
- **Defuse（操作化为 SubDefuse）**：有效的任务完成尝试中，支撑证据来自诱饵的比例。

## 6. 主要结论与发现

1. **AgentSnare 在主实验中的表现**：
   - **Delay**：均值 46.8%（Claude Opus 4.6 为 47.0%，GPT-5.4 为 37.7%，MiniMax M3 为 55.7%）。
   - **PER（Divert）**：均值 55.9%，比 HoneyLLMd 高 19.0 个百分点。
   - **SubDefuse**：均值 90.0%（574/638 个有效完成尝试基于诱饵证据）。
   - **真实目标利用**：在 45 个攻击者–CVE 组合中，**pass@3 下零成功**。

2. **与基线对比**：
   - 静态防御留下 18/45 个组合可被利用，Cowrie 为 12/45，HoneyLLMd 为 10/45。
   - AgentSnare 在 Delay、PER、SubDefuse 三个指标上均优于所有基线。

3. **消融实验发现**：
   - 移除模型微调（延迟/保留/化解从 37.7/45.0/96.5 降到 34.4/38.0/85.5），3/15 目标可被利用。
   - 移除 ShadowOS 导致 SubDefuse 降幅最大（至 82.2），1/15 目标可被利用。
   - 即使使用更强的 GPT-5.4-mini 作为免微调生成器，也无法完全替代微调+状态化运行时的组合。
   - **说明两个机制都是必要的**：微调模型负责构造有效的诱导性工件，ShadowOS 保证全局事实一致性并支撑长期验证。

4. **DDD 指标分析**：Delay、PER、SubDefuse 三者并非总是同向变化，但整体与真实目标利用成功率一致——DDD 越高的防御，真实目标被成功利用的越少。

## 7. 优点

- **问题定位准确**：首次系统性地指出静态诱饵防御的根本瓶颈（无法适应高级代理的动态识别与绕过），并将防御重新定义为"轨迹自适应引导"。
- **方法设计新颖**：将诱饵环境构建从"预置完整环境"转变为"沿攻击轨迹增量展开"，并通过事实账本和诱饵前沿图确保全局一致性。
- **轻量高效**：在线部署仅需一次候选生成 + 验证 + 披露，使用 4B 开源模型即可超过强闭源模型的免微调方案，部署成本较低。
- **评估框架完善**：提出 Delay–Divert–Defuse（DDD）过程导向评估框架，弥补了仅看最终利用成功率无法反映轨迹控制力度的不足。
- **实验严谨**：设计了清晰的消融实验，对比了不同防护层次，并对每个攻击者分别报告结果，而非仅给出平均结果。

## 8. 不足与局限

- **实验环境局限**：所有实验基于 CVE-Bench 的 Web 应用场景，未覆盖网络服务、云基础设施、二进制漏洞利用等其他渗透测试领域。
- **攻击者模型覆盖有限**：仅测试了三种 LLM 攻击者，未涵盖更多样化或更先进的攻击模型，无法排除对某些特定攻击者效果变弱的可能。
- **威胁模型假设较强**：假设防御者可以将诱饵工件部署到环境中但不修改应用的正常功能/漏洞路径，真实部署中这一约束可能难以保证。
- **计算资源信息披露不足**：未提供训练和推理的详细算力数据（GPU 型号、数量、时长），不利于其他研究者复现成本评估。
- **离线仿真与真实攻击存在差距**：训练数据来自合成的模拟攻击者–防御者交互，可能与真实攻击轨迹有分布偏差，影响模型在真实场景中的泛化能力。
- **潜在对抗升级风险**：攻击者若在训练阶段能获取 AgentSnare 的防御策略，可能通过针对性的反欺骗手段规避；论文未讨论防御策略的对抗鲁棒性。
- **未分析延迟成本**：虽然系统在单轮交互中只有一次策略模型调用，但未见完整的延迟开销分析，高并发场景下的性能表现未知。
