## 摘要
外包环境中的大规模生物识别需要同时满足两个特性：生物特征模板和查询在计算过程中必须受到保护，并且由不可信计算节点生成的加密相似性输出在发布任何应用结果之前必须是可验证正确的。现有的基于FHE的生物识别系统主要解决保密性问题，而实际的可验证性在底层加密的1:N匹配层引入了两个瓶颈：轮转和带宽密集的相似性评估，以及证明重复同态相似性迹的高昂成本。我们提出了BioZKFHE，一个通过可验证同态相似性评估实现可扩展加密生物识别的框架，该框架结合了BGV同态计算与委员会调解的证明打开/解密以及打开证明批次的智能合约验证。为了减少加密存储并避免轮转密集的加密1:N匹配，我们提出了单系数多值（SCMV）打包，通过基T展开将多个量化嵌入值绑定到每个明文条目中。为了使证明生成实用化，我们提出了可并行化和可验证相似性计算（PVSC），利用BGV的双CRT执行结构将每个块状相似性迹分解为并行证明实例，在结果发布之前打开并检查这些实例。在标准格假设和明确的委员会/验证者假设下，我们分析了可恢复性、噪声增长、保密性、加密输出完整性和最终结果完整性。在FaceNet和MobileFaceNet上的实验显示，生物识别效用几乎无损，加密存储减少高达67%，对于10k到40k个模板，端到端证明验证运行时间约为22到44秒。

## Abstract
Large-scale biometric identification in outsourced settings requires two properties simultaneously: biometric templates and queries must remain protected during computation, and the encrypted similarity outputs produced by an untrusted compute node must be verifiably correct before any application result is released. Existing FHE-based biometric systems primarily address confidentiality, while practical verifiability introduces two bottlenecks in the underlying encrypted 1:N matching layer: rotation- and bandwidth-heavy similarity evaluation and the high cost of proving repeated homomorphic similarity traces. We present BioZKFHE, a framework for scalable encrypted biometric identification via verifiable homomorphic similarity evaluation that combines BGV homomorphic computation with committee-mediated proof opening/decryption and smart-contract verification of opened proof batches. To reduce encrypted storage and avoid rotation-heavy encrypted 1:N matching, we propose Single-Coefficient Multi-Value (SCMV) packing, which binds multiple quantized embedding values into each plaintext entry through base-T expansion. To make proof generation practical, we propose Parallelizable and Verifiable Similarity Computation (PVSC), which exploits the Double-CRT execution structure of BGV to decompose each blockwise similarity trace into parallel proof instances that are opened and checked before result release. Under standard lattice assumptions and explicit committee/verifier assumptions, we analyze recoverability, noise growth, confidentiality, encrypted-output integrity, and finalized-result integrity. Experiments on FaceNet and MobileFaceNet show near-lossless biometric utility, up to 67 percent encrypted-storage reduction, and about 22 to 44 seconds end-to-end proof-verified runtime for 10k to 40k templates.

- **研究动机**：在外包场景中进行大规模生物识别（如区块链辅助的身份认证）时，系统需要**同时**满足两个关键属性：生物特征模板与查询在计算过程中必须始终保持加密（机密性）；不可信计算节点产生的加密相似性输出必须在释放结果前被验证为正确（可验证性）。
- **现有瓶颈**：现有基于全同态加密（FHE）的生物识别系统主要解决保密性，但可验证性存在两大瓶颈：
  1. **旋转与带宽开销**：加密 1:N 匹配中常见的打包技术（SIMD 槽位）仍依赖昂贵的密文旋转和槽位聚合，随着数据库增长，延迟和通信开销显著增加；
  2. **证明成本高**：对重复的同态相似性迹做整体性证明（monolithic proof）电路规模庞大、并行性有限，导致证明生成延迟过高。
- **整体含义**：BioZKFHE 构建了首个同时优化加密匹配效率与证明可扩展性、并集成区块链智能合约进行公开验证的框架，为基于 FHE 的外包生物识别提供了兼具**机密性、完整性和可扩展性**的落地路径。

## 2. 方法论

- **总体架构**：由四个实体组成：
  - **Client Device**（数据所有者，持有 fhe 公钥，提取并加密生物特征）；
  - **Compute Node**（不可信计算节点，执行离线加密 1:N 匹配并生成证明）；
  - **Decryption Committee**（阈值信任锚点，\((t, n_{com})\) 门槛共享密钥，负责打开证明和解密）；
  - **Blockchain Smart Contract**（公开验证器和状态门卫，验证打开后的证明批次、记录已接受块索引、门控最终化）。

- **核心贡献之一：Single-Coefficient Multi-Value (SCMV) 打包**
  - 通过基 \(T\) 展开，将 \(n\) 个量化嵌入值绑定到每个明文多项式系数中（即每个明文条目），从而将单个块的覆盖模板数从 \(d\) 提升到 \(nd\)；
  - 消除在线相似性路径中的密文旋转操作，加密匹配只需进行 ciphertext–ciphertext 乘法和累积；
  - 数据库更新（新增用户）可在不解密的情况下，通过同态加法将新模板合并到最后一个部分填充块中，保持 SCMV 布局不变；
  - 参数推导：最小安全基 \(T = 2\lfloor \Gamma^2 + \Gamma\sqrt{L} + 0.25L \rfloor + 1\)；最大绑定因子 \(n_{\max} = \lfloor \log_T( p(T-1)/(2D) + 1 ) \rfloor - 1\)，由明文模数 \(p\) 和相似度上界 \(D\) 共同决定。

- **核心贡献之二：Parallelizable and Verifiable Similarity Computation (PVSC)**
  - 利用 BGV 的 Double-CRT（RNS + NTT）执行结构，将每个块状相似性迹分解为大量均匀形状的本地证明实例；
  - 每个块被证明的计算迹为：\(p_{m,i} = \mathrm{Relin}(c^{\mathrm{id}}_i \otimes c_{m,i})\)，\(a_{m}^{0} = 0\)，\(a_{m}^{i} = a_{m}^{i-1} \oplus p_{m,i}\)，终止条件 \(a_{m}^{L} = c^{\mathrm{sim}}_m\)；
  - 证明实例计数：\(K_m = n_q n_{\mathrm{chunk}} (2L - 1)\) 个算术/输出实例加上 1 个块级绑定实例；证明生成可并行化，实测 122–125× 加速比；
  - 打开流程：计算节点先生成**加密的** PVSC 证明对象 → 委员会阈值打开 → 智能合约解析、检查描述符序列、验证打开的证明批次 → 记录接受块索引 → 全覆盖后启用阈值解密 → 最终化输出。

- **安全模型与形式化保证**：
  - 假设多项式时间内敌手可控制计算节点、聚合方以及最多 \(t-1\) 个委员会成员；
  - 形式化定义了四个安全目标：G1（生物特征机密性）、G2（加密输出完整性）、G3（最终结果完整性）、G4（后量子安全）；
  - 在标准格假设（Ring-LWE）下给出三个安全定理，证明方案满足上述目标；
  - 证明生成和验证范围明确限定为深层-1 线性迹（乘–重线性化–累积），不覆盖旋转、模交换、bootstrapping 等扩展操作。

## 7. 优点

- **结构创新**：SCMV 在明文条目层面进行多值基 \(T\) 绑定，而非传统槽位/系数级打包，在保持匹配规则不变的前提下，提高有效打包密度并消除旋转，设计巧妙且易于融入现有 BGV 流程。
- **可并行性设计**：PVSC 基于 Double-CRT 天然分解，将大电路拆分为大量同构的局部证明，使证明生成高度并行化，克服了可验证 FHE 的主要性能瓶颈。
- **完整安全推导**：包含参数（\(T, n\)）优化、噪声增长上界分析、游戏化安全定义（G1–G3）和主定理（Theorem 1–3），安全论证层次清晰。
- **系统集成度高**：将 FHE、ZVK、阈值解密、区块链合约组合为端到端协议，角色和信任假设明确，且采用公开承诺 + 合约状态跟踪来防止回放、重排、缺失和重复等攻击行为。
- **可复现性**：开源了实现代码和实验脚本，参数（约 135–243 位安全强度）和测量方式均有详细记录。

## 8. 不足与局限

- **证明域宽度有限**：PVSC 目前只覆盖深度为 1 的乘–重线性化–累积迹，不包含旋转、模交换、bootstrapping、非线性层或 Top-K/阈值决策电路；对更深的 BGV 电路需要扩展描述符语言（本文仅给出扩展路径，未实现）。
