## 摘要
微软的活动目录（AD）是一种目录服务，使IT管理员能够管理Windows域网络中的安全权限并控制访问。作为许多组织的核心管理系统，AD已成为 adversaries 的主要目标。尽管已有许多加固攻击图的解决方案，但这些努力在解决AD攻击图特有的几个关键实际挑战方面仍显不足。首先，现有模型通常假设图是静态的，而真实世界的AD环境是高度动态的。其次，大多数提出的解决方案仅限于撤销漏洞（边缘移除）这一防御措施，而更积极的防御机制在很大程度上尚未被研究。第三，由于并非所有修复措施都可实施，一个实用的端到端模型必须将系统管理员反馈纳入优先级排序过程。本论文旨在通过研究并提出若干基于博弈论和优化的决策模型来解决这些局限性。首先，我们提出一个基于最小化最短路径数量和域管理员可达节点数量原则的蜜罐/诱饵放置模型。其次，在此模型基础上，我们引入一种考虑AD图动态/时间特性的防御策略，其目标是找到最大化最坏情况下事件响应时间的诱饵部署位置。第三，我们引入一种自适应优先级排序模型，向IT管理员查询每条高风险攻击路径以进行调解。最后，我们引入一个端到端的自适应优先级排序模型，通过找到一种通用的自适应边缘移除策略，将系统管理员的决策泛化到具有相似风险特征的边缘，从而最小化系统管理员的审批工作量。我们表明，所有贡献模型所基于的问题在计算上是难处理的。

## Abstract
Microsoft's Active Directory (AD) is a directory service that enables the IT admin to manage security permissions and control access within a Windows domain network. As a core management system in many of organisation, AD has become a primary target for adversaries. While many solutions for hardening attack graphs exist, these efforts fall short in addressing several key practical challenges specific to the AD attack graph. First, existing models often assume the graph is static, whereas a real-world AD environment is highly dynamic. Second, most proposed solutions are limited to the defensive measure of revoking vulnerabilities (edge removal), while more active defence mechanisms are largely unstudied. Third, because not all remediations are implementable, a practical end-to-end model must incorporate system admin feedback into the prioritisation process. This thesis aims to address these limitations by studying and proposing a number of game-theoretic and optimisation-based decision-making models. First, we propose a honeypot/decoy placement model based on the principle of minimising the number of shortest paths and the number of Domain Admin-reachable nodes. Second, building on this model, we introduce a defence strategy that considers the dynamic/temporal nature of the AD graph, where the objective is to find the location to deploy decoys that maximises the worst-case incident response time. Third, we introduce an adaptive prioritisation model that queries each high-risk attack path to the IT administrator for mediation. Finally, we introduce an end-to-end adaptive prioritisation model that minimises the approval effort of the system admin by finding a general adaptive edge-removal policy that generalises the system admin's decisions to edges with similar risk features. We show that the problems underlying all of the contributed models are computationally intractable.

## 二、方法论与核心贡献

论文共提出四套模型，每套均证明了底层优化问题的计算难解性（NP-hard / W[1]-hard / #P-hard），并设计了从精确算法到启发式/AI方法的解决方案。

### 1. 第3章：静态与动态 AD 网络中的蜜罐部署
- **模型**：攻防 Stackelberg 博弈。防御者部署蜜罐（节点阻塞），考虑两类攻击者——"简单攻击者"（无法识别蜜罐，走最短路径）与"有能力的攻击者"（完全可观测蜜罐，会绕行）。
- **目标函数**：最小化两类攻击者综合成功率 zφ,i = φR_Bi + (1−φ)·(y_Bi/y_i)，其中 R 表示可达性，y 表示最短路径数量。
- **算法**：
  - 静态图：混合整数规划（sMIP），利用 AD 图的树状结构加速求解；
  - 动态图：扩展为多图 MIP（dyMIP(m)），提出基于投票的（Voting）与基于 k-means 聚类的（Kmean）两种启发式，从代表性图快照中求解防御策略；
  - 同时给出动态策略最优值的下界（分批求解），并用 Hoeffding 不等式估计蒙特卡洛模拟所需样本数（n=100,000 时误差约 ±5.147×10⁻³）。
- **复杂度**：针对简单攻击者 NP-hard（L≥7），针对有能力攻击者 W[1]-hard。

### 2. 第4章：时序 AD 网络中的诱饵部署与响应时间优化
- **模型**：将 AD 图建模为时间有向图，边仅在特定时间间隔内激活；攻击路径是时间戳非降的时序路径，可刻画攻击者"潜伏等待"的行为。
- **新指标**：**响应时间（Response Time）**——从攻击者触发第一个诱饵到攻陷 DA 的时间差，防御者最大化最坏情况下的响应时间以争取事件响应窗口。
- **算法**：
  - 基于 Dijkstra 的最早到达路径算法（利用 AD 图中静态边占绝大多数的特性，比 SOTA 的 Wu 算法快约 5 倍）；
  - 进化多样性优化（EDO）主框架，附带两种约束处理技术：
    - **ILP 修复算子**：用整数规划直接修补不可行解；
    - **代理辅助（Surrogate-assisted）**：用"重要路径集"上的轻量代理适应度函数评估解，并证明该过程在 O(|V|) 次更新后收敛到全局可行解。
- **复杂度**：NP-hard（归约自 strict temporal separator 问题）。

### 3. 第5章：自适应攻击路径移除向导（Adaptive Path Removal, APR）
- **模型**：人在环路模型——向导每一步提出一条从源 s 到目标 t 的攻击路径，IT 管理员依据 Bradley–Terry 模型从路径中选择一条边移除（概率与边置信度成正比）。过程持续到 s-t 断开或达到查询预算。
- **算法**：
  - 精确算法 OPT（动态规划/Bellman 方程），借助"动作空间 ⊆ 根状态动作空间"引理避免重复枚举；
  - 近似算法 APP（利用自适应子模性框架，证明 (ln|P|+1)² 近似比）；
  - 可扩展启发式 DPR（带限制的动态规划，限制前瞻步数与候选路径数量 τ），以及 PPO/SAC 两种 RL 启发式。
- **复杂度**：#P-hard（归约自 (s,t)-网络可靠性问题）。

### 4. 第6章：基于特征的 adaptive 连通性测试（F-ACT）
- **模型**：每条边关联 d 维二值特征向量，管理员决策由隐藏的决策函数 f(x)（权重 w、偏置 b）决定边的 ON（保留）/OFF（移除）状态。提出**单调风险推断规则**：若某边被判定 OFF，则所有特征超集边也 OFF；反之亦然，从而单次查询可推广到全网。
- **算法**（RL4FT）：以 SAC 为基座，三个创新组件：
  - **启发式引导的自我改进机制**：以次优策略/H1 启发式为参考，RL 策略逐步扩大探索步数，外层循环将学到的策略作为下一轮参考，迭代提升；
  - **策略不变的奖励塑形**：基于潜在函数 g(s)=|P||C|−(|P|−|P_OFF|)(|C|−|C_ON|)，并证明塑形奖励在任意终态取值恒定，因此不改变最优策略；
  - **自定义优先经验回放**：对启发式策略产生的转换施加指数衰减权重 βτ，避免过采样导致的分布偏移。
- **复杂度**：#P-hard（归约自 LQGCT 问题）。

### 第5章实验
- **数据集**：ADSynth 生成 9 张合成图（G1–G9，节点数 1,047–10,070）+ 4 张小图（GS1–GS4，供精确算法运行）+ 1 张真实组织 AD 图（ORG，125,444 节点、1,195,432 边）。
- **对比方法**：OPT（仅小图）、APP、OTH1（最小割启发式）、OTH2（最短路径上的 APP）、PPO、SAC、DPR。每图 16,000 次试验（ORG 为 200 次）。
- **额外对比**：与 Guo 等 LQGCT 模型的 RL 算法（表5.3）比较成功割断次数；并报告查询路径长度。

### 第6章实验
- **数据集**：10 个真实网络——5 个 ADSynth AD 图（AS1–AS5）+ 1 个真实大学 AD 图（UNI，125K 节点）+ 4 个杂项网络（EUROROAD、MINNESOTA 道路网、BCSPWR05/10 电网）。
- **对比方法**：H1、GREEDY、HMC（粒子滤波）三种启发式 + SAC、PPO、LIMIT 三种 RL 基线 + RL4FT 系列变体（RL4FT(SAC)+H1、RL4FT(PPO)+H1、RL4FT(SAC)+LIMIT 等）。
- **额外实验**：
  - 消融研究（表6.5）：去掉奖励塑形/迭代改进/启发性引导/PER 的性能下降幅度；
  - 稳健性测试：非线性决策函数（二次模型、RBF 核模型）；
  - 轨迹长度分布分析、自改进迭代曲线。
- **指标**：期望查询次数（越低越好）。

## 六、主要结论与发现

1. **计算难解性**：四个模型的核心优化问题分别为 NP-hard（第3章静态简单攻击者、第4章）、W[1]-hard（第3章有能力攻击者）、#P-hard（第5、6章）。最优策略在一般图上不可行，必须依赖近似/启发式算法。
2. **MIP 的高效性**：第3章 sMIP 在约 10 万节点、100 万边的图上可在数十秒内求解，得益于 AD 图天然近似树状结构；动态图上静态最优策略显著退化（成功率明显恶化），验证了

动态图上静态最优策略显著退化（成功率明显恶化），验证了**动态防御策略的必要性**：将静态最优解直接用于动态图会导致防御效果大幅下降，而基于图快照的投票/聚类启发式能显著恢复性能，这说明动态环境下的防御策略必须考虑时变信息。

3. **进化算法与代理模型在时序网络上的优势**：第4章中，基于 EDO 的代理辅助方法在保证最终解全局可行的前提下，运行速度和内存占用均优于 ILP 修复方法；而 ILP 修复在多个实例中因内存溢出失败，证明精确方法难以直接扩展到大规模时序 AD 网络。响应时间作为新指标，比单纯的可达性度量更能反映攻击者的“潜伏等待”行为对防御窗口的影响。

4. **人在环路模型的实际可操作性**：第5章的 APR 框架将管理员反馈建模为 Bradley–Terry 概率选择，并在真实 12.5 万节点的 AD 图上，DPR 启发式仅用少量查询即可实现高概率割断，且与 OTH 等基线相比大幅减少查询次数；自适应子模近似比在实际运行中表现稳定，说明将人类专家引入优化循环在计算上是可行的，且有理论保证。

5. **特征归纳显著降低查询负担**：第6章的 RL4FT 借助“单调风险推断规则”将单条边查询的结果推广到特征超集/子集，在各类真实网络上将期望查询次数降至传统 HMC 等方法的 1/2 至 1/5；消融实验证实奖励塑形、迭代自我改进、启发式引导与 PER 四组件均对性能有贡献，且对非线性决策函数具备良好的稳健性，表明该框架可超越线性评分假设，适配更复杂的管理员行为。

6. **跨章节共性规律**：所有章节的核心均说明，AD 攻击图并非一般性复杂网络，其近似树状、高度分层、节点角色分明的结构特征可以被算法设计利用；针对 AD 特性的定制化方法（MIP 加速、时间路径剪枝、自适应子模、特征归纳）比通用图算法在规模、速度、稳定性上均有显著提升。同时，理论复杂度结果（NP-hard / W[1]-hard / #P-hard）提醒实际部署必须依赖启发式或机器学习方法，而非追求全局最优。

## 七、总体评价

### 贡献与亮点
- **理论深度扎实**：每个模型均给出严格的复杂度证明与近似比分析，并提供了可复现的算法细节。
- **实用导向明确**：研究问题直接源于企业 AD 加固的真实痛点，实验数据融合合成图与真实认证日志，方法设计上兼顾了计算资源、管理员交互和动态环境等现实约束。
- **方法多样性**：混合了博弈论、时序网络、进化计算、强化学习、整数规划等多种技术，并在同一框架下进行了系统比较，展现了跨方法的视野。

### 局限与不足
- **模型假设的简化**：攻击者行为（最短路径/全知绕行）、管理员决策（Bradley–Terry / 线性特征函数）等均是对真实世界的理想化抽象，实际场景可能更复杂、更嘈杂。
- **规模验证的失衡**：精确算法只能跑极小的示例图，而大规模实验几乎全部依赖启发式/RL，缺少针对中等规模图的最优性对照，导致“近似算法性能损失”的量化不够充分。
- **真实数据代表性存疑**：所有“真实”AD 图与认证日志均来自匿名组织，无法确认其结构代表性；合成图生成器的参数（如边密度、层级比例）可能影响结论的一般性。
- **计算资源描述粗略**：论文未提供 GPU 训练的具体耗时、能耗或成本，不利于其他研究者复现时的资源规划。

### 展望
未来工作可沿三个方向深化：一是将更多真实的攻击者策略（如利用零日、鱼叉攻击）纳入博弈模型；二是将第5、6章的人机交互扩展到在线学习，让算法能够实时适应管理员偏好的变化；三是设计统一的、可部署的软件原型，将蜜罐部署、时序诱饵、自适应移除和特征查询集成为一个端到端的 AD 加固平台。
